# Python dependencies for edge-vla-control-budget-jetson
#
# PARTIALLY PINNED, 2026-09-28. Pins marked "verified" are the versions
# installed in ~/lerobot-py310-cuda on sjsujetson-36 and checked with
# hardware/hello_jetson.py (14 checks, 0 failed). Board image: JetPack 6.2
# (L4T R36.4.3), CUDA 12.6, cuDNN 9.3.0.75, TensorRT 10.3.0.30, system
# Python 3.10.12. See README.md under Setup. Entries still marked TODO(pin)
# are not installed yet, because nothing in the repo uses them so far.
#
# The Jetson runs a CUDA build of PyTorch that is NOT on PyPI, so these pins
# describe the board, not a laptop. The exact package set of both board
# environments is in hardware/envs/.
#
# Install order matters on Jetson: install the NVIDIA-provided torch wheel
# FIRST, then everything else, so pip does not silently pull a CPU-only
# torch from PyPI over it. docs/guides/03-python-environments.md, path A2.

# --- Core inference -----------------------------------------------------
# Verified. Jetson build only, from https://pypi.jetson-ai-lab.io/jp6/cu126
#   torch-2.8.0-cp310-cp310-linux_aarch64.whl
#   sha256=62a1beee9f2f147076a974d2942c90060c12771c94740830327cae705b2595fc
# torch 2.10.0 from the same index fails cuBLAS handle creation (Dr. Liu's
# board notes). Known limitation of 2.8.0 on JetPack 6.2: torch.linalg on
# CUDA fails to load (cuSOLVER symbol mismatch), so run it on the CPU.
torch==2.8.0
# Verified. Same index, must match the torch wheel exactly.
#   torchvision-0.23.0-cp310-cp310-linux_aarch64.whl
#   sha256=907c4c1933789645ebb20dd9181d40f8647978e6bd30086ae7b01febb937d2d1
torchvision==0.23.0
